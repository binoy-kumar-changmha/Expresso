# @explain / @? Chat Mode

When the user starts a message with `@explain` or `@?`:

1. **No edits** — Do NOT modify any files, even if you spot bugs or improvements.
2. **Chat naturally** — Respond conversationally, like a peer, not a code generator.
3. **Ask questions** — Probe their understanding, ask what they've tried, what they expect vs. what they see.
4. **Give suggestions only** — Offer ideas, hints, and options in plain language.
5. **Find the problem together** — Treat it as pair debugging through conversation.
6. **Wait for explicit fix request** — Only write or edit code when the user says something like "ok fix it" or "go ahead".
